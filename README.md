# Mobile


## Comandos úteis
- Formatar: `./gradlew spotlessApply`
- Corrigir erros de code-smell: `./gradlew detekt --auto-correct`
- Rodar testes unitários: `./graldew testDebugUnitTest`
- Rodar testes de instrumentação (precisa de um dispositivo conectado): `./gradlew connectedDebugAndroidTest`
- Validar cobertura de testes (precisa de um dispositivo conectado): `./gradlew jacocoTestCoverageVerification`
